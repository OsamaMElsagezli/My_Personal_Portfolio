Targa Vehicle Marketplace & Auctions

Developed an Arabic-first marketplace and auction platform for the Libyan market. Targa brings vehicles, motorcycles, heavy equipment, special license plates, live bidding, listings, wallet activity, and account management into one responsive mobile experience.

Category: Mobile App and Full-Stack Development

Tools: Flutter, Dart, Riverpod, Dio, GoRouter, Python, Django, Django REST Framework

Role: Mobile UI development, backend API development, authentication, auction workflows, wallet integration, and RTL design

Project Demo

Project Features

  • Complete Arabic interface with right-to-left layout support
  • Search and category browsing for vehicles, motorcycles, equipment, and license plates
  • Active-auction discovery with category filters, sorting, current prices, and bid counts
  • Authenticated bidding through the backend API
  • Listing-creation interface with image selection, vehicle details, pricing, and location validation
  • Wallet balance, deposit requests, payment evidence, approval status, and transaction history
  • User profile, activity statistics, favorites, notifications, and application settings
  • Responsive layouts designed for phones and tablets

Technical Highlights

  • Feature-organized Flutter application using Riverpod for state and data management
  • Dio-based HTTP communication and GoRouter navigation
  • Django REST Framework backend split into accounts, bidding, catalog, and payments modules
  • JWT authentication with tokens stored through Flutter Secure Storage
  • Backend endpoints for registration, login, user profiles, wallets, auctions, bids, and deposits
  • Image selection and processing for listings and deposit evidence
  • Django administration workflow for reviewing deposit requests
  • Listing-submission interface prepared for a future create-listing API endpoint

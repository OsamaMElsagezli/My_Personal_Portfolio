Novai Technology Business Platform

Developed the official bilingual Arabic and English marketing website for Novai Technology. The Django platform presents the company’s services, portfolio, pricing, and offices while allowing the team to manage content and customer enquiries through a compact CMS and REST API.

Category: Full-Stack Web Development

Tools: Python, Django, Django REST Framework, PostgreSQL, HTML, CSS, JavaScript

Role: Full-stack development, CMS architecture, API integration, responsive UI, security, and deployment

Project Demo

Project Features

  • Complete Arabic and English experience across the public website
  • CMS-managed services, portfolio items, pricing packages, and city offices
  • Responsive layouts for desktop, tablet, and mobile visitors
  • Validated contact form with database storage and instant email notifications
  • Libya-focused phone validation using the +218 dialing format
  • Portfolio showcase for the company’s mobile, web, and digital projects
  • Search-engine support through automatically generated robots.txt and sitemap.xml files
  • Optional Cloudinary integration for persistent uploaded media

Technical Highlights

  • Django application architecture divided into leads, pages, product, and services modules
  • Django REST Framework endpoint for validated lead submission
  • PostgreSQL database integration for production data
  • Brevo API integration for contact-form email delivery
  • Production delivery through Gunicorn and WhiteNoise
  • Render deployment blueprint with automatic builds and database migrations
  • HTTPS enforcement, HSTS, secure cookies, API rate limiting, and spam protection
  • Environment-based configuration for secrets, hosts, email, database, and cloud media
